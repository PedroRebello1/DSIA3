# Steam RecSys

API de recomendação de jogos da Steam, construída com FastAPI, PostgreSQL e um modelo híbrido
(filtragem colaborativa, conteúdo e popularidade).

> Projeto em desenvolvimento. Instruções completas de instalação e uso serão adicionadas em breve.

## Dataset

[Steam Video Games](https://www.kaggle.com/tamber/steam-video-games) (Kaggle, Tamber), na versão processada do
repositório [caserec/Datasets-for-Recommender-Systems](https://github.com/caserec/Datasets-for-Recommender-Systems/tree/master/Processed%20Datasets/Steam).
